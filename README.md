# 🧱 PnB (Put & Break) Script

Automated Put & Break (PnB) script for Growblox.

## 🚀 How to Execute (Loadstring)

Copy and execute the following loadstring in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/s160424169/pnb/main/pnb.lua"))()
```

### Anti-Cache Version (Recommended):
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/s160424169/pnb/main/pnb.lua?v=" .. tostring(os.time())))()
```
